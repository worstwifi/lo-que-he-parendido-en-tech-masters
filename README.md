# Tech Master — Lo que aprendimos

Landing page educativa hecha como una recopilación estudiantil de los temas trabajados en el taller **Tech Master**.

## Temas incluidos
- Qué es SVG y algunos de sus elementos.
- Cambios de color en gráficos SVG.
- Animaciones y transiciones realizadas con la misma herramienta usada para trabajar los SVG.
- Funciones y etiquetas básicas de HTML.
- Introducción a electrónica básica, componentes, Arduino UNO y ESP32.
- Zona interactiva con personalizador de colores, quiz y calculadora de Ley de Ohm.

## Ejecutar en Windows

1. Instala Python.
2. Abre CMD dentro de esta carpeta.
3. Ejecuta:

```bash
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

La página se abrirá en el navegador, normalmente en `http://localhost:8501`.

**Nota:** La aplicación que muestra la landing page está hecha con Python y Streamlit. Eso no significa que Python, CSS o JavaScript sean temas que se hayan aprendido en el taller. El contenido refleja únicamente los temas que se describieron como parte de Tech Master.
